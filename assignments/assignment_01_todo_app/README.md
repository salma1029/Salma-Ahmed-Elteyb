# Flutter To-Do App

A simple **To-Do List mobile application** built using **Flutter**.  
Users can add, complete, and delete tasks with a clean, Material Design interface.

---

## 📌 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Real-time updates
- Simple and modern UI

---

## 🎨 Design

**Color Palette:**

| Color | Hex Code | Usage |
|-------|---------|-------|
| Blue | #5F52EE | Add button, checkbox |
| Red | #DA4040 | Delete button |
| Black | #3A3A3A | Task text |
| Grey | #717171 | Secondary text |
| Light Grey | #EEEFF5 | Background |
| White | #FFFFFF | Task cards, input field |

**Fonts:**
- Font sizes:
  - 30 → Screen title
  - 16 → Task text
  - 40 → Add button "+"
